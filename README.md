# appandroid
All app build for android
Android 5.0 and above
the app build is version 2.0 and above
if you want use app build version 1.0: https://sites.google.com/view/downloadapkai?pli=1&authuser=0 (not safe)
use app build version 2.0 and above is safe
I recommend using version 2.0 or higher for security, as version 1.0 apps are not secure. I've used android-ide! Version 2.0 and above apps will use GitHub for the best security! 

tiếng việt: 
Tất cả các bản dựng ứng dụng dành cho Android
Android 5.0 trở lên
Bản dựng ứng dụng là phiên bản 2.0 trở lên
Nếu bạn muốn sử dụng bản dựng ứng dụng phiên bản 1.0: https://sites.google.com/view/downloadapkai?pli=1&authuser=0 (không an toàn)
Sử dụng bản dựng ứng dụng phiên bản 2.0 trở lên là an toàn
Tôi khuyên bạn nên sử dụng phiên bản 2.0 trở lên để đảm bảo an toàn, vì các ứng dụng phiên bản 1.0 không an toàn. Tôi đã sử dụng android-ide! Các ứng dụng phiên bản 2.0 trở lên sẽ sử dụng GitHub để có độ bảo mật tốt nhất!
